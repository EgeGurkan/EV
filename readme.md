# EV Charge Price & Campaign Tracker ⚡🚗

A modern mobile application designed for Electric Vehicle (EV) owners in Turkey to easily track real-time charging unit prices and discover exclusive promotional campaigns across various charging networks.

## ✨ Features

*   **Real-Time Pricing:** Stay updated with the latest AC, DC, and HPC (High Power Charging) unit prices for major EV charging operators in Turkey (e.g., Tesla, ZES, Trugo, WAT).
*   **Smart Filtering:** Quickly filter charging stations by charger type (AC, DC, HPC) using the intuitive top bar toggles.
*   **Favorites System:** Save your preferred charging operators or stations to access their pricing instantly.
*   **Campaigns & Discounts:** A dedicated tab to explore current partnerships, discounts, and campaigns (e.g., Vodafone Red discounts, Togg special rates).
*   **Promo Code Integration:** Easily copy campaign promo codes with a single tap to use in the respective operator's app.
*   **Last Updated Timestamp:** Always know exactly when the pricing data was last refreshed.
*   **Clean & Modern UI:** Built with a user-friendly, card-based interface and seamless bottom navigation.

## 🚀 Getting Started

### Prerequisites

*   Make sure you have the required SDKs installed (e.g., Flutter SDK, Android Studio, Xcode).
*   An emulator or a physical device for testing.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/ev-charge-tracker.git
   ```
2. Navigate to the project directory:
   ```bash
   cd ev-charge-tracker
   ```
3. Install dependencies:
   ```bash
   # For Flutter:
   flutter pub get
   
   # For React Native:
   npm install
   # or
   yarn install
   ```
4. Run the application:
   ```bash
   # For Flutter:
   flutter run
   
   # For React Native:
   npx react-native run-android # or run-ios
   ```
